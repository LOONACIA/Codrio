# Codrio

> **Cod**e 생성해 드**rio** → **Codrio**
>
> 문자열 이어 붙이느라 고생 많으셨소. 이제 코드는 소인이 생성해 드리오.

C# 소스 코드를 `StringBuilder`로 한 땀 한 땀 이어 붙이다가 중괄호 하나 빠뜨려 본 적 있으시오? 들여쓰기 칸 수를 손가락으로 세어 본 적은?

Codrio는 C# 소스 코드를 fluent 빌더로 조립하는 라이브러리요. 무엇을 만들지만 말씀하시면 들여쓰기, 중괄호, 빈 줄, 키워드 이스케이프는 알아서 맞춰 드리오.

## 이름이 왜 Codrio요?

**"코드 생성해 드리오"** 의 줄임말이오. 영어권 개발자들은 그냥 이탈리아어처럼 들리는 멋진 이름인 줄 알 것이오. 그 비밀은 우리끼리만 알고 있읍시다.

## 무엇을 해 드리오

- **빌더로 조립하면 문자열로 내어 드리오.** 모든 빌더의 `ToString()`이 그 조각을 렌더링하오.
- **포맷은 알아서 맞춰 드리오.** 4칸 들여쓰기, Allman 중괄호, 멤버 사이 빈 줄 1개.
- **키워드는 피해 드리오.** 식별자가 예약 키워드면 `@`를 붙여 드리오 (`class` → `@class`).
- **타입 이름은 풀어 드리오.** `typeof(...)`나 제네릭으로 타입을 주면 `global::` 완전 한정 이름으로 바꿔 드리오.
- **잘못된 조합은 미리 막아 드리오.** enum에 메서드를 넣으려 하면 컴파일부터 안 되오. `EnumBuilder`에는 `Method`가 없으니.
- **짐은 가볍게 해 드리오.** `netstandard2.0` 단일 타깃에 런타임 의존성 0이오. Source Generator 안에서 마음 놓고 쓰시오.

## 설치

```shell
dotnet add package Codrio
```

## 빠른 시작

```csharp
using Codrio;

var file = CSharp.File()
    .AutoGeneratedHeader()
    .NullableEnable()
    .Using("System")
    .FileScopedNamespace("MyApp.Models", ns => ns
        .Class("Person", c => c
            .Public().Partial()
            .Doc(d => d.Summary("사람 한 명을 나타냅니다."))
            .Property<string>("Name", p => p.Public().Initializer("\"\""))
            .Property<int>("Age", p => p.Public().Get().Init())
            .Method("Greet", m => m
                .Public()
                .Returns<string>()
                .Parameter<string>("greeting", p => p.Default("\"안녕하세요\""))
                .Arrow("$\"{greeting}, {Name}님!\""))));

Console.WriteLine(file.ToString());
```

이렇게 생성해 드리오.

```csharp
// <auto-generated/>
#nullable enable

using System;

namespace MyApp.Models;

/// <summary>사람 한 명을 나타냅니다.</summary>
public partial class Person
{
    public string Name { get; set; } = "";

    public int Age { get; init; }

    public string Greet(string greeting = "안녕하세요") => $"{greeting}, {Name}님!";
}
```

## 차림표

모든 빌더는 `CSharp` 정적 클래스에서 시작하오.

### 파일과 네임스페이스

| 메서드 | 출력 |
| --- | --- |
| `AutoGeneratedHeader()` | `// <auto-generated/>` |
| `NullableEnable()` | `#nullable enable` |
| `Using("System")` | `using System;` |
| `Namespace("A.B", ...)` | 블록 네임스페이스 `namespace A.B { ... }` |
| `FileScopedNamespace("A.B", ...)` | 파일 범위 네임스페이스 `namespace A.B;` |
| `Raw("...")` | 적은 그대로 |

헤더 두 줄은 호출했을 때만 나오오. 네임스페이스 없이 `File()`에 바로 타입을 넣어도 되오.

### 타입

| 진입점 | 만드는 것 |
| --- | --- |
| `CSharp.Class(name)` | `class` |
| `CSharp.Struct(name)` | `struct` |
| `CSharp.Interface(name)` | `interface` |
| `CSharp.Record(name)` | `record` |
| `CSharp.RecordStruct(name)` | `record struct` |
| `CSharp.Enum(name)` | `enum` |

- 접근 제한자: `Public()`, `Internal()`, `Protected()`, `Private()`, `ProtectedInternal()`, `PrivateProtected()`
- 수식어: `Static()`, `Abstract()`, `Sealed()`, `Partial()`, `ReadOnly()` 등
- 기반 타입과 인터페이스: `BaseType("Base")`, `BaseType<IDisposable>()`
- 제네릭: `TypeParameter("T", t => t.Constraint("class").Constraint("new()"))`
- 주 생성자: `PrimaryParameter("int", "X")` (class, struct, record). 본문 멤버가 없는 record는 `;`로 끝나오.
- enum 멤버: `Member("Green", "1 << 2")`. 값은 문자열로 받소.
- 중첩 타입과 `Raw()`도 되오.

```csharp
CSharp.RecordStruct("Point", r => r
    .Public().ReadOnly()
    .PrimaryParameter("int", "X")
    .PrimaryParameter("int", "Y", p => p.Default("0")));
// public readonly record struct Point(int X, int Y = 0);
```

### 멤버

`Field`, `Property`, `Method`, `Constructor`, `Indexer`, `Event`, `Delegate`, `Operator`, `ImplicitOperator`, `ExplicitOperator`를 갖추고 있소.

- **속성**: 람다를 생략하면 `{ get; set; }` 자동 속성이오. 람다에서 `Get()`·`Set()`·`Init()`, 접근자 본문, `Arrow(expr)`, `Initializer(expr)`를 고르시오.
- **메서드**: `Returns(type)`를 생략하면 `void`요. `Body(...)`나 `Arrow(expr)`를 주지 않으면 `;`로 끝나오 (인터페이스나 abstract 메서드에 쓰시오).
- **매개변수**: `Parameter(type, name, p => p.Ref() / Out() / In() / Params() / This() / Default(expr))`
- **생성자**: 이름은 담고 있는 타입에서 가져오니 따로 적지 않으셔도 되오.

### 본문

식과 문은 문자열로 받고, 블록만 `Block()`으로 감싸 드리오.

```csharp
CSharp.Method("Clamp", m => m
    .Public().Static()
    .Returns<int>()
    .Parameter<int>("value")
    .Parameter<int>("max")
    .Body(b => b
        .Block("if (value > max)", then => then.Line("return max;"))
        .Line("return value;")));
```

```csharp
public static int Clamp(int value, int max)
{
    if (value > max)
    {
        return max;
    }
    return value;
}
```

`Line()`에 여러 줄 문자열을 넘기면 줄마다 현재 들여쓰기를 붙이고 `\r\n`은 `\n`으로 맞춰 드리오.

### attribute와 XML 문서

```csharp
CSharp.Method("Read", m => m
    .Public().Returns<int>()
    .Attribute("Obsolete", "\"Use ReadAsync\"")
    .Attribute<DescriptionAttribute>("\"reads\"")
    .Doc(d => d
        .Summary("Reads <count> & reports changes.")
        .Returns("The stored count.")));
```

- attribute 인자는 원시 문자열로 받소. `Attribute<T>()`나 `Attribute(typeof(T))`를 쓰면 이름을 `global::`로 풀어 드리오.
- 문서 텍스트는 XML 이스케이프해 드리오 (`<` → `&lt;`). 태그가 필요하면 `d.Xml(raw)`로 원시 XML을 넣으시오. 여러 줄이면 줄마다 `///`를 붙여 드리오.

### 타입 참조와 식별자

| 넘기는 방법 | 출력 |
| --- | --- |
| `"List<int>"` | 적은 그대로 `List<int>` |
| `typeof(int)`, `<int>` | 키워드 별칭 `int` |
| `typeof(Dictionary<string, List<int>>)` | `global::System.Collections.Generic.Dictionary<string, global::System.Collections.Generic.List<int>>` |

- 문자열 타입은 Source Generator에서 `ITypeSymbol.ToDisplayString()` 결과를 그대로 넘기기 좋소.
- `Type` 오버로드는 `global::`로 한정하니 `using`을 신경 쓰지 않으셔도 되오.
- 식별자가 C# 예약 키워드면 `@`를 붙여 드리오. 식별자로 쓸 수 없는 이름(`"1st"` 같은)은 빌더 메서드를 호출하는 순간 `ArgumentException`을 던지오. 잘못된 코드를 생성해 드리느니 그 자리에서 말씀드리는 게 도리이니.

### 조합: 람다로 중첩하거나, `Add()`로 끼워 넣거나

하위 구조는 람다로 바로 만들어도 되고, 따로 만든 빌더를 `Add()`로 붙여도 되오. 심볼을 돌면서 멤버를 하나씩 만드는 Source Generator라면 `Add()`가 편할 것이오.

```csharp
var dto = CSharp.Class("ArticleDto").Public().Sealed();

foreach (var (type, name) in columns)
{
    dto.Add(CSharp.Property(type, name).Public());
}
```

```csharp
public sealed class ArticleDto
{
    public string Title { get; set; }

    public int @class { get; set; }

    public global::System.DateTime CreatedAt { get; set; }
}
```

## 규칙

- **포맷은 고정이오.** 4칸 스페이스, `\n`, 멤버 사이 빈 줄 1개, 중괄호는 새 줄. 옵션은 없소. 탭이냐 스페이스냐 하는 논쟁은 정중히 사양하오.
- **멤버는 넣은 순서대로 나오오.**
- **접근 제한자는 호출하지 않으면 생략하오.** 여러 번 호출하면 마지막 것이 이기오.
- **수식어 조합은 검사하지 않소.** `static abstract sealed` 같은 것은 컴파일러가 따끔하게 일러 줄 것이오.
- **빌더는 가변이고 스레드 안전하지 않소.** 같은 빌더 인스턴스를 여러 곳에 붙이면 변경이 함께 섞이니 조심하시오.

## 해 드리지 않는 것

소인도 할 수 있는 일과 없는 일이 있소.

- **기존 코드 파싱·분석·변환**: 생성만 해 드리오.
- **`If`·`For` 같은 문 전용 API**: C# 문법을 통째로 모델링하게 되오. 문자열과 `Block()`이면 충분하오.
- **주석·전처리기 전용 API**: `Raw()`를 쓰시오.
- **문자열 리터럴 이스케이프 헬퍼**: 식은 문자열로 받는다는 원칙을 지키오.
- **`using` 자동 수집**: 문자열 타입만 보고는 네임스페이스를 알 수 없소. `Type` 오버로드의 `global::`로 해결하시오.
- **LangVersion별 출력 조정**: 버전 호환은 손님 몫이오. 최신 문법은 `FileScopedNamespace()`처럼 명시적 메서드로 고르시오.
- **Roslyn 타입(`SyntaxNode`, `SourceText`) 반환**: 의존성 0을 지키기 위함이오.

## 빌드와 테스트

.NET SDK 10.0.100 이상이 필요하오 (`global.json`). 테스트는 net10.0과 net48에서 돌고, net48은 Windows에서만 실행되오.

```shell
dotnet build Codrio.slnx
dotnet test Codrio.slnx
```

테스트는 출력을 기대 문자열과 글자 하나까지 비교하고, 완결된 파일 단위 출력은 Roslyn으로 컴파일해서 오류가 0개인지까지 확인하오. 생성해 드리는 코드에 책임을 지기 위함이오.
